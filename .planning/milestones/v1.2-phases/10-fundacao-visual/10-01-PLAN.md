    (só `node:fs`, `node:path`, `node:url`). Nenhum pacote novo pode ser instalado nesta fase.

    Exports obrigatórios (contrato consumido pelo plano 02):
    - `RAW_COLOR_PREFIXES` — array das famílias de utilitário listadas no bloco behavior.
    - `RAW_COLOR_FAMILIES` — array dos nomes de paleta listados no bloco behavior.
    - `RAW_COLOR_SCALE` — array dos degraus numéricos.
    - `RAW_COLOR_PATTERN_SOURCE` — string com o source do regex, montada a partir dos três arrays
      acima, sem flags, adequada para ser reusada em outro contexto (o plano 02 monta um seletor
      esquery com ela). Alternância de escala em ordem decrescente (950 antes de 900 antes de 90…)
      e sufixo de borda que rejeita dígito subsequente.
    - `createRawColorRegex(flags)` — devolve um `RegExp` novo a cada chamada a partir de
      `RAW_COLOR_PATTERN_SOURCE`, para nunca compartilhar estado entre chamadas.
    - `scanText(texto)`, `scanPaths(raizes, opcoes)`.

    Casamento: usar `texto.match(createRawColorRegex("g"))` e/ou `texto.split(...)` para localizar
    as ocorrências. O método imperativo de execução de regex com estado (`lastIndex`) é BLOQUEADO
    por hook de segurança do projeto — não usar em nenhuma hipótese; `.split()` + `.match()`
    resolvem o caso inteiro.

    Segurança do padrão: montar o regex apenas com alternâncias literais e quantificadores simples.
    Nada de grupo aninhado com quantificador sobre quantificador — o scanner roda em CI sobre
    arquivos grandes e não pode ter backtracking catastrófico (T-10-02).

    Delimitação de borda: a ocorrência começa em início de string, espaço, aspas simples, aspas
    duplas, crase, `:`, `[`, `(`, `{` ou `;` — isso é o que deixa `hover:bg-red-500` casar e
    `bg-background` não gerar falso positivo pelo miolo.

    do maior para o menor, seguida de `TOTAL: n (m arquivos)`. Exit 0 nesse modo.

    - Teste de fixture em diretório temporário: com um baseline dopado (contagem de um arquivo

  </behavior>

    `compareToBaseline(atual, baseline)`.

    Formato de `design-system/raw-color-baseline.json`:
    - `generatedAt` — ISO string.
    - `command` — o comando que regenera o arquivo.
    - `exceptions` — array de `{ file, reason }`. Gravar exatamente uma entrada:
      `src/app/api/relatorios/catalogo/route.ts`, com a razão de que a rota devolve um documento
      HTML autônomo que carrega Tailwind por CDN, fora do pipeline de tokens do app, e por isso as
