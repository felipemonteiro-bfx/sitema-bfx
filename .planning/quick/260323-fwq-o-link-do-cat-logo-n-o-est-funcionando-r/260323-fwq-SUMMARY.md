## What Was Done

The `/api/catalogo` endpoint generates a PDF catalog of products. It was protected by the authentication middleware and returned 401 when accessed without an active session — breaking external sharing via WhatsApp or AI-generated links.

The fix adds `/api/catalogo` to the `PUBLIC_API_PATHS` array in `src/middleware.ts`. The existing `isPublicApiPath()` function uses `startsWith(p + "/")`, so this single entry covers both `GET /api/catalogo` and any future subpaths.
