navegador usado pelos tres componentes, e os testes que travam os dois formatos.

| banco (`Config.logoPath`) -> `fetch` do servidor nos 4 geradores de PDF | URL vinda do banco e buscada pelo processo do app |
| banco (`Config.logoPath`) -> `src` de `next/image` no navegador | URL vinda do banco vira requisicao do cliente |
| internet -> `/api/catalogo` (rota publica, em `PUBLIC_API_PATHS`) | anonimo dispara a geracao de PDF que carrega a logo |
